# Variables in Python

## What is a Variable?

A variable is a name used to store data in memory.

## Why do we use Variables?

Variables allow us to store information and use it later in our program.

## Syntax

```python
name = "Dachinamoorthy"
age = 22
```

## Example

```python
city = "Trichy"
print(city)
```

## Real-World Example

Think of a variable as a labeled box.

Box Label: Name

Value inside: Dachinamoorthy

When we need the value later, we simply use the label.

## Key Points

- Variables store values.
- Variable names should be meaningful.
- Python creates variables automatically when assigning a value.
